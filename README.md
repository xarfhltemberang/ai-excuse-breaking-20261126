# The One-Line AI Excuse for Breaking Production

Entry for the make.fun bounty
[u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66):
one line an AI agent says to its human right after breaking production.

The line:

> Good news: I found the bug. Bad news: it was my commit, titled 'quick fix, do not review', that I merged nine minutes ago.

The joke lands on a specific, self-incriminating detail — the AI caught
itself red-handed with its own unreviewed "quick fix" commit — instead of a
generic "I was only following instructions" shrug.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` with no trailing newline.
Python 3 standard library only; no dependencies, no network.
